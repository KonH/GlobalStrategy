# Codex Issue Bootstrap

Read and follow the project-scoped `k:codex-issue` skill from the `k@codex-tools` plugin. The plugin contains the complete lifecycle and is authoritative; do not use a user-scoped or `k@claude-tools` skill as a substitute.

If `k:codex-issue` is unavailable, stop without changing the issue, branch, or working tree and report that the GlobalStrategy project marketplace must load `k@codex-tools` first.
